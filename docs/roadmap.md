# Roadmap

## Milestone 0 — Foundation

- [x] Next.js, TypeScript, and Tailwind application setup
- [x] Landing page and event-pack library presentation
- [x] Framework-independent simulation domain types
- [x] Initial documentation

## Milestone 1 — Scenario contract

- [ ] Define points of divergence, basic choices, advanced variable schemas, decision forks, and source-library records
- [ ] Add runtime schema validation
- [ ] Create the reviewed Dunkirk 1940 seed scenario
- [ ] Add unit tests for scenario validation

## Milestone 2 — Deterministic prototype

- [ ] Implement graph traversal and intervention validation
- [ ] Add seeded pseudo-random sampling
- [ ] Produce three to five ranked branch outputs
- [ ] Support 1, 5, and 10-year horizons

## Milestone 3 — Results experience

- [ ] Scenario setup page
- [ ] Branch comparison and timeline
- [ ] Period-inspired headline cards with modern explanations
- [ ] Symbolic map and world indicators
- [ ] Evidence and assumptions view

## Milestone 4 — Interaction and transparency

- [ ] Advanced controls
- [ ] Decision-fork pauses
- [ ] Full horizon set, including 50 years and present day
- [ ] Versioned source library and causal-chain explorer

## Milestone 5 — Narration and sharing

- [ ] Hosted model adapter
- [ ] Ollama adapter
- [ ] Source-grounded narrative generation
- [ ] Immutable public share links
- [ ] Rate limits, observability, accessibility review, and deployment

## Deferred intentionally

- Authentication and personal libraries
- User-authored public scenario packs
- Live web retrieval
- High-fidelity territorial or economic simulation
- Multiplayer play and community voting
